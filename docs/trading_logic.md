# 투자 판단 로직

# 목적

이 문서는 AI 투자 판단 기준을 정의한다.

실제 판단은 GPT가 수행한다.

Python은 투자 판단을 하지 않는다.

---

# 기본 판단 유형

AI는 다음 3가지 중 하나를 선택해야 한다.

- BUY
- SELL
- HOLD

---

# BUY 조건

다음 요소가 긍정적일 경우 BUY 가능:

- 시장 흐름 긍정적
- 뉴스 긍정적
- 기술 지표 긍정적
- 리스크 낮음
- confidence 높음

---

# SELL 조건

다음 요소가 부정적일 경우 SELL 가능:

- 시장 악화
- 리스크 증가
- 악재 뉴스 발생
- confidence 감소

---

# HOLD 조건

다음 상황에서는 HOLD 우선:

- 데이터 부족
- 방향성 불확실
- 리스크 과도
- confidence 낮음

---

# Confidence 규칙

confidence 범위:

```text
0.0 ~ 1.0
```

예시:

```text
0.2 → 매우 낮음
0.5 → 중립
0.8 → 높은 확신
```

---

# 중요 규칙

- AI는 반드시 판단 이유를 설명해야 한다.
- AI는 반드시 리스크를 설명해야 한다.
- 정보 부족 시 HOLD 우선.
- 높은 confidence라도 리스크 설명 필수.
