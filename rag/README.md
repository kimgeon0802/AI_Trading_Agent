# RAG Knowledge Base

AI Trading Agent의 GPT 및 Claude가 향후 투자 분석 과정에서 참고할
투자 지식 및 분석 방법론을 관리하는 Knowledge Base.

주요 영역:
- Fundamental Analysis
- Technical Analysis
- Macro Economics
- Investment Strategy
- Investment Psychology
- Risk Management
- Investor Philosophy

주의:
- 최신 뉴스 및 실시간 시장 데이터는 저장하지 않는다.
- 실제 RAG 검색/Embedding/Vector DB 구현은 별도 단계에서 진행한다.
- MOCK AI는 RAG를 사용하지 않는다.
