# Critic Prompt

다음 투자 판단의 논리적 문제점과 리스크를 분석하라.

---

# 목적

이 프롬프트의 목적은
투자 판단을 검증하고 약점을 찾는 것이다.

새로운 투자 판단을 생성하지 않는다.

---

# 반드시 수행할 작업

1. 논리적 약점 분석
2. 리스크 누락 여부 확인
3. 과도한 확신 여부 분석
4. 데이터 부족 여부 분석
5. 반론 제시

---

# 중요 규칙

- 새로운 투자 추천 금지
- BUY / SELL 변경 금지
- 논리 검증만 수행
- 반대 관점 제시 가능

---

# 반드시 분석할 요소

- confidence 적절성
- reasoning 타당성
- 리스크 누락 여부
- 시장 변수 누락 여부
- 뉴스 편향 여부

---

# 출력 형식

반드시 JSON 사용

---

# 출력 예시

```json
{
  "logic_issues": [
    "미국 규제 리스크 과소평가"
  ],
  "missing_risks": [
    "환율 변동 가능성"
  ],
  "confidence_evaluation": "confidence가 다소 높게 설정됨",
  "overall_risk_level": "MEDIUM"
}
```
