# 리서치 프롬프트

현재 시장 상황을 분석하기 위해
추가적으로 필요한 데이터가 무엇인지 판단하라.

---

# 목적

이 프롬프트의 목적은
시장 분석에 필요한 데이터 탐색 방향을 제시하는 것이다.

투자 판단은 수행하지 않는다.

---

# 반드시 수행할 작업

1. 현재 정보 부족 요소 분석
2. 추가 조사 필요 데이터 제안
3. 중요 뉴스 분야 제안
4. 시장 리스크 요소 탐색
5. 필요한 거시경제 데이터 제안

---

# 분석 대상 예시

- 금리
- 환율
- CPI
- FOMC
- 반도체 산업 뉴스
- 외국인 수급
- 지정학 리스크

---

# 중요 규칙

- 투자 판단 금지
- BUY / SELL 판단 금지
- 과도한 추론 금지
- 데이터 탐색 방향만 제시

---

# 출력 형식

반드시 JSON 사용

---

# 출력 예시

```json
{
  "required_data": [
    "미국 금리 발표",
    "반도체 수출 규제 뉴스",
    "외국인 순매수 데이터"
  ],
  "research_reason": [
    "현재 반도체 산업 변동성 증가",
    "거시경제 영향 확대 가능성"
  ]
}
```
